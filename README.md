CampusConnect – Placement & Internship Management Portal
Week 1: Project Planning & System Architecture
Tech stack: MongoDB · Express.js · React.js · Node.js (MERN)
Project Brief
CampusConnect is a full stack web application that connects students, recruiters and the placement admin on one platform. It replaces scattered notice boards, WhatsApp groups and spreadsheets with a secure, role-based portal.
Key Features
JWT authentication with role-based access (Student, Recruiter, Admin)
Student profile and resume upload
Job posting, search and filtering
One-click job application with duplicate prevention
Applicant shortlisting and status tracking
In-app and email notifications
Admin approvals and reports
Architecture
Three-tier: React front-end → Node/Express REST API (JWT, validation, Multer) → MongoDB + cloud file storage.
